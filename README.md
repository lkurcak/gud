# gud

Interactive git helper.

## Install

```sh
brew install lkurcak/tap/gud
```

or

```sh
cargo install gud
```

## Usage

```sh
gud b   # interactively switch to or delete local branches
gud l   # browse commits; soft/hard reset or edit a commit message
```
